# Finylys Academy - Financial Literacy SaaS

## Overview
A gamified financial literacy SaaS platform inspired by Finylys. Features structured learning tracks, interactive lessons with quizzes, payment simulation for module unlocking, progress tracking, and admin capabilities.

## Technical Stack
- Database: PostgreSQL with Prisma ORM
- Auth: NextAuth.js v4 with credentials provider (email/password, bcrypt)
- Styling: Tailwind CSS with custom finance-themed design tokens
- Animations: Framer Motion

## Color Scheme
- Primary: Emerald green (HSL 160 84% 39%)
- Secondary: Blue (HSL 217 91% 60%)
- Track colors: Green (#10B981), Blue (#3B82F6), Purple (#8B5CF6), Amber (#F59E0B)

## Database Schema
- User (roles: LEARNER, ADMIN)
- Track → Module → Lesson hierarchy
- UserProgress (lesson completion + quiz scores)
- UserModuleAccess (payment/unlock tracking)

## Key Design Decisions
- Lesson format: Hook → Content → Quiz → Complete (4-step flow)
- Free modules (isFree: true) accessible without payment
- Payment simulation via button click (no real gateway)
- Quiz data stored as JSON string in Lesson.quizData
- Admin panel with overview stats, user management, lesson CRUD

## Pages Structure
- `/` - Landing page (redirects to dashboard if logged in)
- `/login`, `/signup` - Auth pages
- `/dashboard` - User dashboard with progress overview
- `/academy` - All learning tracks
- `/academy/[trackId]` - Track detail with modules
- `/module/[moduleId]` - Module detail with lesson list
- `/lesson/[lessonId]` - Interactive lesson viewer
- `/profile` - User profile with detailed progress
- `/admin` - Admin panel (role-gated)
